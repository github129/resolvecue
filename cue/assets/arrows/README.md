# 矢印 PNG 素材

このディレクトリに以下のファイル名で PNG を配置してください。

| ファイル名         | 方向                   |
| ------------------ | ---------------------- |
| `arrow_tr.png`     | 右上 (top-right)       |
| `arrow_r.png`      | 右   (right)           |
| `arrow_br.png`     | 右下 (bottom-right)    |
| `arrow_b.png`      | 下   (bottom)          |
| `arrow_bl.png`     | 左下 (bottom-left)     |
| `arrow_l.png`      | 左   (left)            |
| `arrow_tl.png`     | 左上 (top-left)        |
| `arrow_t.png`      | 上   (top)             |
| `arrow_c.png`      | 中央指し (center)      |

- 透過 PNG
- 推奨サイズ 1920x1080 (位置決めはエフェクト側で 0.0-1.0 の正規化座標)
- 矢印は「画面のどこに矢印が表示されるか」基準で命名する
  - 例: `arrow_tr.png` = 画面右上に矢印が表示され、被写体 (中央付近) を指す形
